# Character art goes here

Export your Storyline customer poses into this folder. The app maps the validated
emotion to `/<emotion>.png` (lowercase), and the Customize screen uses `presenter.png`.

Expected files:

```
presenter.png      (the greeter on the Customize screen)
interest.png
confusion.png
skepticism.png
impatience.png
frustration.png
concern.png
excitement.png
neutral.png        (the fallback — always include this one)
```

Tight head-and-shoulders crops of ONE consistent character read best. Until these
exist, CharacterImage shows a labeled placeholder so the app still runs.
